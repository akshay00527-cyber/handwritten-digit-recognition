

\# Handwritten Digit Recognition Using Deep Learning



\## About

A deep learning application that recognizes handwritten digits (0–9) drawn by users on a digital canvas.



\## Features

\- Draw digits using a mouse.

\- Predict handwritten digits from 0 to 9.

\- Display prediction confidence.

\- Visualize prediction probabilities.



\## Technologies Used

\- Python

\- TensorFlow

\- Streamlit

\- NumPy

\- MNIST Dataset



\## Model

\- Dataset: MNIST

\- Input: 28 × 28 grayscale images

\- Hidden Layer: Dense layer with 128 neurons and ReLU activation

\- Output Layer: 10 neurons with Softmax activation



\## Installation



```bash

pip install -r requirements.txt

```



\## Run the Application



```bash

streamlit run app.py

```
